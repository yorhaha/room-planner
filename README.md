# 栖居 Roomly · 房间规划

一个轻量、可视化、会自动保存的房间规划工具。用 2D 平面图编辑户型，实时查看 3D 效果。

## 功能

- **房间编辑**：添加、拖动、拖角/边调整尺寸；拖动时边缘自动吸附，重合的墙自动合并为一堵。
- **门窗编辑**：在墙上点击放置门/窗，沿墙拖动换位置；可调整宽度、高度、窗台高度和所在墙面，3D 墙体自动开洞。
- **家具布置**：内置 22 种常用家具（沙发、床、餐桌、橱柜、卫浴等），支持拖动、15° 旋转、换色、复制和删除。
- **实时 3D**：2D/3D 一键切换；墙体可切换半透明、实心、隐藏；支持旋转、缩放、平移和重置视角。
- **自动保存**：改动约 0.4 秒后自动保存到浏览器 `localStorage`；同时支持 JSON 导入/导出备份。
- **常用能力**：撤销/重做、快捷键、示例户型、空白项目、开门窗提示、面积与尺寸统计。

## 运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

打开 http://localhost:5173/ 。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

## 使用提示

- **房间**：点击顶部工具栏「房间」添加；拖动房间内部移动，拖动边缘或角点调整尺寸。靠近其他房间时松手会自动吸附。
- **门窗**：点击「门 / 窗」，再点击平面图中的墙。放置后直接拖动门窗可沿墙移动；右侧检查器可精确调整尺寸与位置。
- **家具**：点击左侧家具库中的家具添加；拖动移动，选中后拖动上方圆点旋转，右侧可改颜色或复制。
- **保存**：自动保存到当前浏览器；换设备或清理浏览器数据前，请用顶栏「导出」保存 JSON。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `V` | 选择工具 |
| `D` | 添加门 |
| `W` | 添加窗 |
| `R` / `Shift+R` | 旋转家具 ±15° |
| `Delete` / `Backspace` | 删除选中对象 |
| `⌘/Ctrl+Z` | 撤销 |
| `Shift+⌘/Ctrl+Z` 或 `Ctrl+Y` | 重做 |
| `⌘/Ctrl+D` | 复制家具 |
| 方向键 / `Shift`+方向键 | 微调选中对象 |
| `1` / `2` | 切换 2D / 3D |
| `F` | 适应平面视图 |
| `空格` + 拖动 | 平移画布 |
| `Esc` | 取消选择 / 退出工具 |

## 技术栈

React 18 + TypeScript + Vite；状态管理使用 Zustand；3D 使用 Three.js、@react-three/fiber 与 @react-three/drei；平面编辑器为自绘 SVG。
